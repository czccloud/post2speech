# 默认 profile

> 个性层：只覆盖因人而异的偏好，几行就够。共性规则在 `references/core.md`，不在这里重复。
> 条目与 core 冲突时以本文件为准。想换成你自己的：复制本文件为 `profiles/<你的名字>.md`，逐项改成你的习惯——最准的校准方式是录一段你自己的朗读、拿 ASR 转写稿和原文对比（方法见 README「定制你自己的 profile」）。

## 句长

- 默认按 core：分句不超过 15 字，句长拉开落差。没有额外收紧或放宽。

## 口头禅与填充词

- 默认偏好："其实""呢""嘛"为主；不主动用"就是说""那个"。
- "嗯"的位置：只放在回答开头或改口处，不放进句中。

## 数字写法

- 沿用 core.md 风格开关 1 的默认：精确数字一律阿拉伯数字，约数/泛指/序数用中文。

## 停顿节奏

- 话题切换处用"X 呢，"式停顿领起，不用"关于 X"开头。
- 列举不超过三项一口气说完，超过就回环（见 core 口语规则 12）。
