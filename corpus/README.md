# corpus/ — 固定测试输入集

每版规则文件（`references/core.md`）都要在这里的全部输入上跑一遍，检查各题材无退化（见根目录 `README.md` 测试方法）。

- 一个题材一个文件，追加新段落时标注来源，已收录的内容不删不改（回归需要稳定基准）
- 当前题材：`tech.md`（技术）、`meeting.md`（会议总结）、`story.md`（故事）、`opinion.md`（评论）、`news.md`（新闻）、`guide.md`（教程/说明文）
- 每段之间用 `---` 分隔，段首标注编号和来源，方便校准记录引用（如 `corpus/tech.md 第 2 段`）
