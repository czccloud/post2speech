# LLM 评委提示词

用途：回归或 A/B 测试产出大量改写结果、人耳听不过来时，让另一个模型先筛一遍，标出明显退步的段落，人再集中复查（对应根 `README.md` 测试方法表的「LLM 评委」一行）。

**使用边界：LLM 评委的结论只能用于筛查，不能作为通过依据。它替代不了人耳和 ASR 校准。** 评委说"没问题"的段落照样要抽听；评委说"有问题"的段落必须人工复查后才能定性。

## 提示词模板

把下面这段发给评委模型（用与当前迭代不同的模型，避免同模型互相放水），`{{规则文件}}` 替换为被测模型的规则文件全文，`{{输入}}`、`{{输出}}` 替换为待评内容：

---

你是一个口语化改写的评审。评判标准不是"文笔好不好"，而是"这段文字读出来像不像一个真人在说话"。

附件是该改写任务遵守的规则文件，请先通读：

{{规则文件}}

现在评估下面这次改写：

【原始书面输入】
{{输入}}

【AI 改写输出】
{{输出}}

按四个维度各打 1-5 分（1 = 明显机器腔，5 = 完全像人话），并给出依据：

1. **口语化程度**：语气词、填充词、毛边、句长落差是否自然；还是句句工整、像念稿。
2. **停顿与断句**：按气息断句还是按语法断句；有没有一口气读不完的长句；并列多项是否压成了长句。
3. **书面腔残留**：是否命中规则文件「禁用清单」里的词或句式（逐条列出命中的编号）。
4. **规则命中**：对照规则文件主体规则，有没有明确违反的条目（列出编号）。

输出格式：

```
维度1 口语化程度：X/5 —— 依据
维度2 停顿与断句：X/5 —— 依据
维度3 书面腔残留：X/5 —— 命中禁用清单第 N 条：……（没有则写"未命中"）
维度4 规则命中：X/5 —— 违反规则第 N 条：……（没有则写"未违反"）
总评：（一句话，指明最该让人耳复查的点）
```

---

## 结果怎么用

- 任一维度 ≤ 2 分 → 该段落标记为疑似退步，进入人工复查清单。
- 全部 ≥ 4 分 → 通过快筛，仍按 RUNBOOK 抽查。
- 评委结果填进 `results/` 当次归档文件的「LLM 评委快筛」一节，不单独存档。
